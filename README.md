# Vera Pagos — website

Static one-page site for **Vera Pagos**, a Colombian *pagadora* that receives U.S. income for entertainment talent (creators, influencers, streamers, actors, studios) and pays it out in Colombian pesos.

- `index.html` — the whole site (HTML + CSS + JS inline). Bilingual: Spanish by default, EN toggle in the header.
- Always renders in light mode (Apple-style), regardless of the visitor's system theme.
- Links to the sister company [Green Room Global](https://greenroomglobal.co) for U.S. company formation and taxes.

## Before launch

- Confirm the contact email (`hola@verapagos.co` is a placeholder) and the final domain; add a `CNAME` file for GitHub Pages once the domain is set.
- Set real fees. Figures in the hero phone and example cards are illustrative.
- The application form does not submit anywhere yet: it builds a summary the applicant copies and emails.
- Have counsel review the compliance wording (SARLAFT, Ley 1581 de 2012, "not a bank" disclaimer).

## Deploy

GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
